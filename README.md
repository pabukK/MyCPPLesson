## 怎么学

1. 按顺序学,不要跳课。内存那几课依赖前面的内容。
2. 每段代码都亲手敲一遍,不要只看。
3. 每课末尾的练习一定要做。
4. 看不懂就停一下,回到上一课复习,再继续。
