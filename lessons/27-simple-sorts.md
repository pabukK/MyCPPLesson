## 1. 先说明:实际工程里怎么排序

第 19 课学过,实际写程序时,直接用 `std::sort`,又快又可靠,不需要自己写。

那为什么还要学?三个原因:

1. 排序是最经典的算法问题,理解它,能培养你"设计步骤"的思维。
2. 面试和考试经常考。
3. 其中的思想(比如"分成两半处理"、"一边处理一边维护有序")会在别的算法里反复出现。

这一课和下一课,我们学排序是**怎么做到的**。本课先学三种简单的,它们都是 `O(n²)`(第 25 课),数据多了会慢,但容易理解,而且在数据很少时反而好用。

所有排序示例,都是把一个 `vector<int>` 从小到大排好。为了方便,我们把"交换两个元素"用标准库的 `std::swap`:

```cpp
std::swap(a, b);   // 交换 a 和 b 的值
```

## 2. 冒泡排序

**想法:** 从头到尾,比较相邻的两个数,如果前面的比后面大,就交换。这样走一趟,最大的那个数就"冒"到了最后面。再走一趟,第二大的冒到倒数第二个位置。重复,直到全部有序。

像水里的气泡,大的慢慢浮到水面。

用 `{5, 3, 8, 1}` 演示第一趟:

```text
5 3 8 1   比较 5 和 3,5 > 3,交换 -> 3 5 8 1
3 5 8 1   比较 5 和 8,不用换
3 5 8 1   比较 8 和 1,8 > 1,交换 -> 3 5 1 8
```

第一趟结束,最大的 8 到了最后。接下来只需要处理前 3 个。

```cpp
// file: bubble_sort.cpp
#include <iostream>
#include <utility>
#include <vector>

void bubble_sort(std::vector<int>& v) {
    int n = v.size();
    for (int round = 0; round < n - 1; round++) {
        bool swapped = false;
        for (int i = 0; i < n - 1 - round; i++) {
            if (v[i] > v[i + 1]) {
                std::swap(v[i], v[i + 1]);
                swapped = true;
            }
        }
        if (!swapped) {
            break;
        }
    }
}

int main() {
    std::vector<int> v = {5, 3, 8, 1, 9, 2};
    bubble_sort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

运行结果:

```text
1 2 3 5 8 9 
```

逐处看:

- 参数 `std::vector<int>& v` 是引用(第 10 课),这样才能直接改动调用者的数据。
- 外层 `round`:一共最多 `n - 1` 趟。
- 内层 `i < n - 1 - round`:每一趟,末尾已经排好的数不用再比,所以范围越来越小。
- `swapped`:如果某一趟一次交换都没发生,说明已经有序了,提前结束。这个小优化让"本来就有序"的数据只需要 `O(n)`。

**复杂度:** 两层循环,`O(n²)`。数据已经有序时,借助 `swapped`,只要 `O(n)`。

## 3. 选择排序

**想法:** 在没排好的部分里,**选出最小的**,放到最前面。然后在剩下的部分里再选最小的,放到第二个位置。依此类推。

像挑苹果:从一筐里挑出最小的放第一位,再从剩下的里挑出最小的放第二位。

```text
5 3 8 1     在全部里选最小的 1,和第一个位置的 5 交换 -> 1 3 8 5
1 3 8 5     在后三个里选最小的 3,已经在第二个位置,不动
1 3 8 5     在后两个里选最小的 5,和 8 交换 -> 1 3 5 8
```

```cpp
// file: selection_sort.cpp
#include <iostream>
#include <utility>
#include <vector>

void selection_sort(std::vector<int>& v) {
    int n = v.size();
    for (int i = 0; i < n - 1; i++) {
        int min_index = i;
        for (int j = i + 1; j < n; j++) {
            if (v[j] < v[min_index]) {
                min_index = j;
            }
        }
        std::swap(v[i], v[min_index]);
    }
}

int main() {
    std::vector<int> v = {5, 3, 8, 1, 9, 2};
    selection_sort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

运行结果:

```text
1 2 3 5 8 9 
```

- `i`:现在要确定的位置。`i` 之前的部分已经排好了。
- 内层循环:在 `i` 到末尾的范围里,找最小值的下标 `min_index`(注意存的是**下标**,不是值)。
- 最后把最小值和位置 `i` 交换。

**复杂度:** 不管数据长什么样,都要两层循环比较,永远是 `O(n²)`。但它的**交换次数很少**(最多 `n - 1` 次)。如果交换一次的代价特别大(比如元素是很大的对象),选择排序有它的好处。

## 4. 插入排序

**想法:** 像打扑克牌时整理手牌。左手是已经理好的牌,右手每次摸一张新牌,**插到左手牌里正确的位置**。

```text
{5, 3, 8, 1}
已排好:[5]          新牌 3  -> 插到 5 前面 -> [3 5]
已排好:[3 5]        新牌 8  -> 比 5 大,放最后 -> [3 5 8]
已排好:[3 5 8]      新牌 1  -> 从后往前比,3、5、8 都比它大,都往后挪一格,1 放最前 -> [1 3 5 8]
```

```cpp
// file: insertion_sort.cpp
#include <iostream>
#include <vector>

void insertion_sort(std::vector<int>& v) {
    int n = v.size();
    for (int i = 1; i < n; i++) {
        int card = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > card) {
            v[j + 1] = v[j];
            j--;
        }
        v[j + 1] = card;
    }
}

int main() {
    std::vector<int> v = {5, 3, 8, 1, 9, 2};
    insertion_sort(v);
    for (int x : v) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

运行结果:

```text
1 2 3 5 8 9 
```

- `i` 从 1 开始,`v[0]` 自己一个数,天然是有序的。
- `card` 是这次"摸到的牌",先拿出来存好。
- `while`:从 `card` 前一个位置往回看,只要前面的数比 `card` 大,就把它往后挪一格(`v[j + 1] = v[j]`),给 `card` 腾位置。
- 循环结束时 `j + 1` 就是 `card` 该待的位置。
- `j >= 0` 必须写在 `&&` 的**前面**。第 4 课说过 `&&` 是从左到右判断的,左边为假就不再判断右边。如果反过来写,`j` 变成 -1 时会去访问 `v[-1]`,越界(第 7 课)。

**复杂度:** 最坏(完全倒序)`O(n²)`;但数据**基本有序**时,每张牌只需要挪几格,接近 `O(n)`。所以它在"几乎排好序"的数据上很快。

## 5. 实测对比

我在自己的机器上,对 5000 个数据测了各种排列情况(单位:毫秒,没开优化,你的数字会不同,看相对大小):

| 数据的样子 | 冒泡 | 选择 | 插入 |
| --- | --- | --- | --- |
| 随机 | 71 | 36 | 23 |
| 已经有序 | 0.01 | 33 | 0.02 |
| 完全倒序 | 105 | 34 | 46 |
| 基本有序(只乱了 20 对) | 33 | 33 | 0.3 |

从表里能看出:

- **选择排序**,不管数据什么样都差不多,因为它总是做同样多的比较。
- **冒泡和插入**,遇到有序的数据极快,因为它们能"提前发现不用做"。
- **基本有序**时,插入排序远远领先。
- 随机数据上,插入排序通常是三者中最快的。

另外,我对这三个函数各用 300 组随机数据(长度 0 到 39,包含大量重复值的情况),和 `std::sort` 的结果逐个对比,全部一致。**写完排序,一定要这样对拍:用随机数据,和标准库的结果对比。**

## 6. 什么叫"稳定"

有两个同分的学生:小明 90 分,小红 90 分,原来小明在前。按分数排序后,同分的两人,**原来的先后顺序有没有保持?**

- 保持了:这个排序是**稳定**的。
- 可能打乱:**不稳定**。

为什么要在意?比如你先按名字排好了序,再按分数排序。如果分数的排序是稳定的,那么同分的人仍然按名字排列,正是你想要的。

| 排序 | 稳定吗 |
| --- | --- |
| 冒泡 | 稳定(只交换"严格大于"的相邻元素,相等的不动) |
| 插入 | 稳定(挪的条件是 `v[j] > card`,相等就停,不越过) |
| 选择 | **不稳定**(交换会把元素扔到很远的地方) |

选择排序为什么不稳定?看 `{3a, 3b, 1}`(两个 3 的值相同,用 a、b 区分原来的顺序):第一轮选出最小的 1,和第一个位置的 3a 交换,得到 `{1, 3b, 3a}`。两个 3 的顺序被颠倒了。

这三种里,冒泡和插入的写法里,比较用的是 `>` 而不是 `>=`,这一点很关键:如果写成 `>=`,相等的元素也会被交换,稳定性就没了。

## 7. 怎么选

- **数据很少**(几十个以内):插入排序最简单、最快,甚至比复杂的排序更快。标准库的 `std::sort` 内部,对小片段也会用插入排序。
- **数据基本有序**:插入排序。
- **交换代价特别大**:选择排序(交换次数最少)。
- **冒泡排序**:在实际工程里几乎不用,主要用来教学。
- **数据多了**:用下一课的高效排序,或者直接 `std::sort`。

## 小结

- 冒泡:反复交换相邻的逆序对,大的往后"冒"。
- 选择:每次选出剩余部分最小的,放到前面。
- 插入:像整理扑克牌,把每个数插入到已排好部分的正确位置。
- 三种都是 `O(n²)`。冒泡和插入遇到有序数据能提前结束,接近 `O(n)`。
- 稳定排序:相等的元素保持原来的先后顺序。冒泡、插入稳定,选择不稳定。
- 写完排序一定要和 `std::sort` 对拍。
- 实际工程里,直接用 `std::sort`。
