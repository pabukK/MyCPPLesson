# 第 2 课:变量与数据类型

## 这一课你会学到

- 变量是什么,怎么创建和修改
- 常用的几种数据类型:整数、小数、字符、真假、文字
- 给变量起名字的规则
- 用 `const` 定义不能修改的值

## 1. 变量是什么

程序运行时需要记住很多东西:玩家的分数、用户输入的名字、商品的价格。这些东西要放在**内存**里(第 1 课提过,内存是电脑运行程序时临时存放数据的地方)。

**变量**就是给内存里一小块地方起的名字。你可以把变量想成一个贴了标签的盒子:标签是变量的名字,盒子里装的是数据,这个数据叫变量的**值**。

创建变量时,要告诉编译器两件事:盒子里装什么种类的东西(**类型**),以及盒子叫什么名字。

```cpp
// file: variables.cpp
#include <iostream>

int main() {
    int age = 18;
    std::cout << "年龄:" << age << std::endl;

    age = 19;
    std::cout << "过了一年:" << age << std::endl;
    return 0;
}
```

运行结果:

```text
年龄:18
过了一年:19
```

逐行看:

- `int age = 18;` 创建一个名叫 `age` 的变量,类型是 `int`(整数),初始的值是 18。这一步叫**定义**变量,其中 `= 18` 叫**初始化**。
- `age = 19;` 把盒子里的值换成 19。这一步叫**赋值**。注意这里前面没有 `int`,因为变量已经创建过了,不需要再创建一次。
- `std::cout << age` 输出的是变量里的值,不是 `age` 这三个字母。如果写成 `"age"`(带引号),输出的就是三个字母了。

**`=` 在 C++ 里不是"相等",而是"把右边的值放进左边的变量"。**

## 2. 常用的数据类型

不同的数据,要用不同的盒子来装。下面是最常用的五种:

| 类型 | 装什么 | 例子 |
| --- | --- | --- |
| `int` | 整数 | `42`、`-7`、`0` |
| `double` | 带小数点的数 | `3.14`、`-0.5` |
| `char` | 单个字符 | `'A'`、`'7'` |
| `bool` | 真或假 | `true`、`false` |
| `std::string` | 一段文字 | `"你好"`、`"hello"` |

```cpp
// file: types.cpp
#include <iostream>
#include <string>

int main() {
    int score = 95;
    double price = 19.9;
    char grade = 'A';
    bool passed = true;
    std::string name = "小明";

    std::cout << name << " 得了 " << score << " 分,等级 " << grade << std::endl;
    std::cout << "价格:" << price << std::endl;
    std::cout << "是否及格(1 表示真,0 表示假):" << passed << std::endl;
    return 0;
}
```

运行结果:

```text
小明 得了 95 分,等级 A
价格:19.9
是否及格(1 表示真,0 表示假):1
```

几个要注意的地方:

- `char` 用**单引号**,`std::string` 用**双引号**。`'A'` 是一个字符,`"A"` 是一段只有一个字符的文字,两者不是一回事。
- 用 `std::string` 要在开头加 `#include <string>`。
- `bool` 输出时,真显示成 1,假显示成 0。
- 本课程用 `double` 表示小数,不用别的小数类型,这样不用纠结选哪个。

## 3. 变量的名字

名字可以用英文字母、数字和下划线 `_`,但有几条规则:

- 不能以数字开头。`score1` 可以,`1score` 不行。
- 不能有空格。要连起来写,比如 `total_score`。
- 大小写不一样。`Age` 和 `age` 是两个不同的变量。
- 不能用 C++ 已经占用的词,比如 `int`、`return`。这些词叫**关键字**。

好名字能让人一眼看懂。`age` 比 `a` 好,`total_score` 比 `ts` 好。

## 4. 一定要给变量初始值

如果只创建变量,不给初始值,盒子里装的是内存里原来残留的东西,谁也不知道是什么。读取这样的变量,结果是随机的。

```cpp
int count;      // 危险:里面是什么不确定
int count = 0;  // 安全:一开始就是 0
```

**养成习惯:创建变量时,总是同时给它一个初始值。** 这个习惯会在后面的内存课里反复用到。

## 5. 整数的范围

盒子的大小是有限的。`int` 通常能装下大约正负 21 亿的整数。装不下会出错,这叫**溢出**。

```cpp
// file: overflow.cpp
#include <iostream>
#include <climits>

int main() {
    std::cout << "int 能装的最大值:" << INT_MAX << std::endl;
    std::cout << "最小值:" << INT_MIN << std::endl;
    return 0;
}
```

运行结果:

```text
int 能装的最大值:2147483647
最小值:-2147483648
```

平时的数字远远不会超过这个范围。如果要装更大的整数(比如人口总数、文件大小),就用 `long long`,它的范围大得多。现在只需要知道有这回事,不用深究。

## 6. 不能修改的值:const

有些值一旦定好就不应该变,比如圆周率。在类型前加 `const`,这个变量就变成只读的,谁想修改,编译器就报错。

```cpp
// file: const_demo.cpp
#include <iostream>

int main() {
    const double pi = 3.14159;
    double radius = 2.0;
    std::cout << "圆的面积:" << pi * radius * radius << std::endl;
    return 0;
}
```

运行结果:

```text
圆的面积:12.5664
```

试一试:在 `std::cout` 前面加一行 `pi = 3;`,编译时会报错。这是好事:错误在编译时就被发现,不会等到程序运行了才出问题。**不需要改变的值,都加上 `const`。**

## 7. 让编译器猜类型:auto

如果你给了初始值,编译器能看出类型,可以用 `auto` 代替类型名:

```cpp
auto count = 10;     // 编译器知道这是 int
auto price = 9.5;    // 编译器知道这是 double
```

初学时建议先**写出完整的类型名**,这样你自己清楚每个变量是什么。后面看到别人用 `auto` 时,知道它的意思就行。

## 练习

1. 创建变量保存你的名字(`std::string`)、年龄(`int`)、身高米数(`double`),然后在一行里把它们都输出。
2. 创建 `const int days_in_week = 7;`,再试着给它赋值 `8`,看看编译器怎么说。
3. 把 `INT_MAX` 加 1 后输出,看看结果。(提示:先把它存进一个 `int` 变量。输出的数会让你惊讶。)不过要提醒一句:**有符号整数溢出是"未定义行为"**,标准并不保证会得到什么结果。本机只是碰巧按二进制回绕了才看到那个负数,换个平台或换个编译优化级别,结果可能完全不同。真正可靠的做法是:清楚自己需要多大的范围,选用 `long long`。

## 小结

- 变量是内存里一块有名字的地方,有类型和值。
- 常用类型:`int`、`double`、`char`、`bool`、`std::string`。
- `=` 是赋值,把右边的值放进左边的变量。
- 创建变量时总是给初始值。
- 不变的值用 `const`。
