# 第 8 课:内存是什么,变量住在哪里

> 从这一课开始是课程里最重要的部分。很多人说 C++ 难,难的主要就是内存。
> 别担心:我们用 6 节课慢慢讲,每一步只加一点新东西。
> 这一课不写任何危险的代码,只是认识内存。

## 这一课你会学到

- 内存像什么
- 每个变量占多少内存
- 每个变量都有地址,怎么把地址打印出来

## 1. 把内存想成一排带编号的小格子

内存是电脑里临时存放数据的地方。把它想成一条很长的街道,街上有无数个**一样大的小房间**,每个房间有一个**门牌号**。

- 每个小房间能装一个很小的数据。这个小房间的大小叫 **1 字节**。
- 门牌号叫**地址**。电脑靠地址找到数据。

```text
地址:   1000   1001   1002   1003   1004   1005 ...
内容: [ 12 ] [ 0 ] [ 0 ] [ 0 ] [ 7 ] [ 0 ] ...
```

地址是一个很大的整数,通常用十六进制显示(比如 `0x7ffd1234`)。你不需要懂十六进制,只需要知道:**它就是门牌号。**

## 2. 变量占多大的地方

第 2 课说过变量像盒子。现在知道盒子是由一个或几个相邻的小房间组成的。不同类型占的房间数不同。`sizeof` 能告诉你一个类型占几个字节:

```cpp
// file: sizeof_demo.cpp
#include <iostream>

int main() {
    std::cout << "char:   " << sizeof(char) << " 字节" << std::endl;
    std::cout << "bool:   " << sizeof(bool) << " 字节" << std::endl;
    std::cout << "int:    " << sizeof(int) << " 字节" << std::endl;
    std::cout << "double: " << sizeof(double) << " 字节" << std::endl;
    return 0;
}
```

运行结果(在常见的电脑上):

```text
char:   1 字节
bool:   1 字节
int:    4 字节
double: 8 字节
```

所以一个 `int` 变量占 4 个相邻的小房间,一个 `double` 占 8 个。

## 3. 每个变量都有地址

在变量名前面加 `&`,就得到这个变量的地址。这里 `&` 读作"取地址"。

```cpp
// file: address_demo.cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 20;

    std::cout << "a 的值:" << a << ",地址:" << &a << std::endl;
    std::cout << "b 的值:" << b << ",地址:" << &b << std::endl;
    return 0;
}
```

运行结果类似下面这样(地址每次运行都可能不同,不用和我的一样):

```text
a 的值:10,地址:0x7ffc5a3c1d28
b 的值:20,地址:0x7ffc5a3c1d2c
```

观察一下:两个地址只差了 4(`...28` 和 `...2c`,十六进制里 `2c - 28 = 4`)。因为 `int` 占 4 个字节,`b` 就紧挨着 `a` 住。

**一个变量 = 一个地址 + 一个类型 + 一个值。** 地址说明它住哪里,类型说明它占几个房间、里面的内容怎么理解,值就是房间里装的数据。

## 4. 数组在内存里的样子

数组是一排连在一起的格子。看看地址:

```cpp
// file: array_address.cpp
#include <iostream>

int main() {
    int nums[3] = {10, 20, 30};
    for (int i = 0; i < 3; i++) {
        std::cout << "nums[" << i << "] 地址:" << &nums[i] << std::endl;
    }
    return 0;
}
```

运行结果类似:

```text
nums[0] 地址:0x7ffd9e2a4b3c
nums[1] 地址:0x7ffd9e2a4b40
nums[2] 地址:0x7ffd9e2a4b44
```

每个相差 4,一个挨一个,中间没有空隙。这一点很重要:**数组的元素在内存里紧挨着排。** 这就是为什么第 7 课说越界很危险:`nums[3]` 是紧挨着数组后面的那块地,那里住着别的东西。

## 5. 程序结束,内存就还回去

变量创建时,系统分给它一块内存。变量不再需要时(比如第 6 课说的出了大括号),这块内存会被收回,可以给别人用。

内存是**有限**的资源,像租房子:租了要还。后面几课的核心问题就是:**谁来负责还?什么时候还?** 目前用过的所有变量,都是系统自动帮你还的。但在第 11 课,你会学到一种需要自己负责归还的内存,那时问题才真正出现。

## 练习

1. 用 `sizeof` 打印 `long long` 和 `std::string` 占几个字节。
2. 创建一个 `double` 数组,打印每个元素的地址,看看相邻两个的地址差是多少。
3. 创建三个 `int` 变量,打印它们的地址。它们是紧挨着的吗?(不一定,系统可以自由安排。)

## 小结

- 内存是一排带门牌号的小房间,每个房间 1 字节。
- 门牌号叫地址。变量名前加 `&` 得到它的地址。
- `int` 占 4 字节,`double` 占 8 字节。
- 数组的元素紧挨着排列。
- 内存是有限的,用完要还。目前变量的内存都是自动归还的。
