- 写、编译、运行你的第一个程序

## 1. C++ 是什么

C++ 是一种**编程语言**。编程语言是人和电脑沟通用的文字:你把想让电脑做的事写成一行行文字,电脑就照着做。

C++ 有三个特点:

- **快**。游戏、浏览器、操作系统里的很多部分都用 C++ 写,因为它运行得快。
- **能直接管理内存**。内存是电脑运行程序时临时存放数据的地方。这是 C++ 最强的地方,也是最让新手头疼的地方。本课程会专门用一大部分慢慢讲,不用怕。
- **用的人多**。资料多,遇到问题容易搜到答案。

C++ 不算最容易的语言,但学会它以后,再学别的语言会轻松很多。

## 2. 从文字到程序:编译

你写的代码是普通文字,保存在后缀为 `.cpp` 的文件里,这种文件叫**源文件**。电脑的 CPU(负责计算的芯片)看不懂这些文字,它只认由 0 和 1 组成的指令。

所以中间需要一个翻译。这个翻译叫**编译器**,翻译的过程叫**编译**。

```text
源文件 hello.cpp  --编译器翻译-->  程序 hello  --你运行-->  屏幕上出现结果
```

请记住:**改了代码以后,必须重新编译,再运行。** 新手最常见的错误,就是改了代码却忘了重新编译,结果看到的还是旧结果。

## 3. 准备环境

你的 Windows 电脑上原本没有 C++ 编译器。我们用 **WSL** 来解决:WSL 是 Windows 自带的一个小 Linux 系统,可以在里面使用编译器。你的电脑里已经有一个 Ubuntu 24.04,我已经在里面装好了 g++(最常用的 C++ 编译器)、gdb(调试工具)、valgrind(查内存问题的工具)和 cmake(管理大项目的工具)。后面的课会用到它们。

打开环境的方法:

1. 按 `Win` 键,输入 `PowerShell`,打开它。这个黑底(或蓝底)的窗口叫**终端**,你在里面输入文字命令,电脑执行。
2. 输入 `wsl` 然后按回车,进入 Ubuntu。
3. 输入下面这行,进入课程文件夹(这就是你 Windows 里的 `D:\.Project\other\Homework`):

```bash
cd /mnt/d/.Project/other/Homework
```

之后的所有命令,都在这个 WSL 终端里输入。

## 4. 第一个程序

在课程文件夹里新建一个文件夹 `practice`,在里面新建文件 `hello.cpp`,内容如下:

```cpp
// file: hello.cpp
#include <iostream>

int main() {
    std::cout << "你好,C++!" << std::endl;
    return 0;
}
```

逐行解释:

| 代码 | 意思 |
| --- | --- |
| `#include <iostream>` | 把"输入输出"功能拿过来用。没有它,就没法在屏幕上显示文字。 |
| `int main() { ... }` | 程序的入口。电脑运行程序时,从 `main` 里的第一行开始,一行一行往下执行。 |
| `std::cout << "..."` | 把引号里的文字送到屏幕上。`cout` 读作"c-out",意思是"输出"。 |
| `std::endl` | 换行。 |
| `return 0;` | 告诉电脑:程序正常结束。 |
| `;` | 每条语句末尾的分号,相当于中文句子末尾的句号。**忘写分号是新手最常见的错误。** |

## 5. 编译并运行

```bash
cd practice
g++ -std=c++17 -Wall -o hello hello.cpp
./hello
```

屏幕上会出现:

```text
你好,C++!
```

编译命令里每一段的意思:

- `g++`:调用编译器。
- `-std=c++17`:使用 C++17 这个版本的规则。
- `-Wall`:让编译器把可疑的写法都提醒你。建议每次都带上。
- `-o hello`:翻译出来的程序起名叫 `hello`。
- `hello.cpp`:要翻译的源文件。

## 6. 故意犯个错

把 `return 0;` 后面的分号删掉,再编译。编译器会报错,并指出行号。**读报错信息是一项重要的本事**:先看第一条错误,看它指的行号,通常问题就在那一行或上一行。

改回来,重新编译,确认能正常运行。

## 练习

1. 把输出改成你自己的名字,重新编译运行。
2. 再加一行 `std::cout`,让屏幕上显示两行文字。
3. 故意写错 `iostream` 的拼写,看看报什么错。

## 小结

- 源文件要先**编译**成程序,才能运行。
- 改了代码,必须重新编译。
- 每条语句以分号结束。
- 遇到报错,先看第一条。
