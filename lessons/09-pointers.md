# 第 9 课:指针

## 这一课你会学到

- 指针是什么
- 怎么创建指针、通过指针读写数据
- 空指针
- 指针和数组的关系

## 1. 指针就是"记着地址的变量"

上一课你知道了:每个变量都有地址,就是它的门牌号。

**指针**是一种特殊的变量,它里面装的不是普通数据,而是**另一个变量的地址**。就像一张写着门牌号的纸条:纸条本身不是房子,但照着它能找到房子。

```text
变量 a:   地址 1000,值是 10
指针 p:   地址 2000,值是 1000   <- 它装的是 a 的地址
```

我们说:`p` **指向** `a`。

## 2. 创建指针

```cpp
// file: pointer_basic.cpp
#include <iostream>

int main() {
    int a = 10;
    int* p = &a;

    std::cout << "a 的值:" << a << std::endl;
    std::cout << "p 里装的地址:" << p << std::endl;
    std::cout << "a 的地址:" << &a << std::endl;
    return 0;
}
```

运行结果类似(地址每次可能不同):

```text
a 的值:10
p 里装的地址:0x7ffd3b1c2a14
a 的地址:0x7ffd3b1c2a14
```

两个地址一样,说明 `p` 确实记着 `a` 的地址。

逐个符号看:

- `int*` 读作"指向 int 的指针"。星号 `*` 写在类型后面,表示"这是个指针"。
- `&a` 是 `a` 的地址(上一课学过)。
- `int* p = &a;` 的意思是:创建一个指针 `p`,让它指向 `a`。

指针也分类型。`int*` 只能指向 `int`,`double*` 只能指向 `double`。因为电脑要知道:顺着地址找过去,要把几个房间的内容当成什么来读。

## 3. 顺着指针找到数据:解引用

有了地址,就能"顺着纸条找到房子",读或者修改里面的东西。在指针前面加 `*`,就表示"这个地址里的那个东西"。这个操作叫**解引用**。

```cpp
// file: deref.cpp
#include <iostream>

int main() {
    int a = 10;
    int* p = &a;

    std::cout << "通过 p 读到:" << *p << std::endl;

    *p = 99;
    std::cout << "通过 p 修改后,a 变成:" << a << std::endl;
    return 0;
}
```

运行结果:

```text
通过 p 读到:10
通过 p 修改后,a 变成:99
```

`*p = 99;` 的意思是:到 `p` 记着的地址那里,把里面的值改成 99。那个地址就是 `a` 的,所以 `a` 也就变成 99 了。

星号 `*` 在这里有两种完全不同的用法,新手很容易搞混:

| 写法 | 位置 | 意思 |
| --- | --- | --- |
| `int* p` | 创建变量时,写在类型后面 | 声明 `p` 是个指针 |
| `*p` | 使用变量时,写在名字前面 | 解引用:取出指向的那个东西 |

记法:**创建时是"类型的一部分",使用时是"顺着找过去"。**

## 4. 解决第 6 课留下的问题

第 6 课说,普通参数传进去的是复印件,函数改不了外面的变量。有了指针,就可以把**地址**传进去,函数顺着地址去改原来的变量。

```cpp
// file: add_one_ptr.cpp
#include <iostream>

void add_one(int* p) {
    *p = *p + 1;
}

int main() {
    int n = 5;
    add_one(&n);
    std::cout << "n = " << n << std::endl;
    return 0;
}
```

运行结果:

```text
n = 6
```

这次传进去的是 `n` 的地址 `&n`。地址本身是复印件,但复印出来的仍然是同一个门牌号,顺着它找到的还是原来那个 `n`。

## 5. 空指针:没有指向任何东西

指针可以暂时不指向任何东西。这时要让它等于 `nullptr`(读作"空指针")。

```cpp
int* p = nullptr;
```

**绝对不能对空指针解引用。** 因为它没有指向任何有效的房子,顺着找就会出错,程序会崩溃。使用指针前,先检查它是不是空的:

```cpp
// file: null_check.cpp
#include <iostream>

int main() {
    int* p = nullptr;

    if (p != nullptr) {
        std::cout << *p << std::endl;
    } else {
        std::cout << "p 是空指针,不能使用" << std::endl;
    }
    return 0;
}
```

运行结果:

```text
p 是空指针,不能使用
```

还记得第 2 课说的"创建变量要给初始值"吗?对指针来说更重要。**指针创建时,要么指向一个确定的变量,要么设为 `nullptr`。** 如果不写初始值,指针里是随机的地址,指向谁也不知道,这叫**野指针**,是严重的错误来源。

## 6. 指针和数组

上一课说过,数组的元素在内存里紧挨着排。所以指针加 1,就会跳到下一个元素的地址。跳多远由类型决定:`int*` 加 1,地址实际增加 4 字节。

```cpp
// file: pointer_array.cpp
#include <iostream>

int main() {
    int nums[3] = {10, 20, 30};
    int* p = nums;

    std::cout << *p << std::endl;
    std::cout << *(p + 1) << std::endl;
    std::cout << *(p + 2) << std::endl;
    return 0;
}
```

运行结果:

```text
10
20
30
```

- 数组名 `nums` 可以直接当作"第一个元素的地址"使用,所以 `int* p = nums;` 不需要写 `&`。
- `p + 1` 指向第二个元素,`*(p + 1)` 就是第二个元素的值。它和 `nums[1]` 是一回事。

其实方括号 `nums[i]` 的本质,就是 `*(nums + i)` 的简写。这也解释了为什么越界危险:`*(p + 100)` 会毫不犹豫地去 100 个位置之后的地方读数据,不管那里是不是你的。

## 7. 指向常量的指针

如果只想通过指针读数据,不想让别人改,在类型前加 `const`:

```cpp
const int* p = &a;   // 可以读 *p,但写 *p = 1; 会编译失败
```

函数拿到这样的指针,就保证不会改动你的数据。这个用法在后面的课里会经常出现。

## 练习

1. 创建两个 `int` 变量,写一个函数 `void swap_values(int* a, int* b)`,交换它们的值。(这就是第 6 课练习 4 的答案思路。)
2. 创建一个 `int` 数组,用指针加循环,把每个元素加 1,然后输出。
3. 写一个函数,参数是 `int*`,如果是空指针就输出提示并返回,否则输出它指向的值。分别传入空指针和有效指针测试。

## 小结

- 指针是装着地址的变量。`int* p = &a;` 让 `p` 指向 `a`。
- `*p` 解引用:顺着地址找到数据,可以读,也可以改。
- 指针创建时,要么指向确定的东西,要么设为 `nullptr`。
- 不能对空指针解引用。
- 指针加 1,跳到下一个元素。`nums[i]` 就是 `*(nums + i)`。
- 把地址传给函数,函数就能修改外面的变量。
